## 二、 7 天动态增权/降权算法 (7-Day Memory Decay & Boost)

1. **初始写入 (`weight = 1.0`)**：
   * 每次对话结束后（`03 / 回答后的整理`），AI 会在后台异步筛选值得记的事（对方的喜好、近况、黑历史、外号、刚聊过的梗、一起看过的视频），写入或纠正记忆。
2. **提及增权 (`Boost +0.6`)**：
   * 在聊天前（`01 / 先找相关记忆`），如果当前话题命中了某条历史记忆，该记忆的权重自动 `+0.6`（上限 `5.0`），并刷新最后命中时间 `lastHitAt`。越常拿来互怼的梗，权重越高！
3. **7 天自然降权与遗忘 (`Decay`)**：
   * 有效权重计算公式（半衰期 `3.5` 天）：
     `effectiveWeight = weight * (0.5 ^ (未提及天数 / 3.5))`
   * 超过 **7 天**未再提及的普通琐事，有效权重降至 `0.25` 以下，自动归档不再塞入上下文，保持上下文永远精简拟人！
